# Minor Project 04 — React Applications

A React.js minor project containing two interactive web applications:

1. **To-Do App** — Task management application
2. **Notes App** — Note-taking application

This project was developed as part of the **Web Development – Week 04 Minor Project** to demonstrate React fundamentals, advanced JavaScript concepts, component-based architecture, state management, event handling, and React Hooks.

---

## Live links : 
To do List : https://stunning-gelato-2b085a.netlify.app/
Notes app : https://stalwart-selkie-fb78b8.netlify.app/


## 📌 Projects

### 1. To-Do App

A task management application that allows users to organize and manage their daily tasks.

#### Features

* Add new tasks
* Edit existing tasks
* Delete tasks
* Mark tasks as completed
* Display Pending/Completed status
* Task filtering

  * All
  * Pending
  * Completed
* Add task due dates
* Local Storage persistence
* Responsive design
* Light/Dark mode
* Violet gradient UI

---

### 2. Notes App

A note-taking application that allows users to create and manage notes.

#### Features

* Create new notes
* Edit existing notes
* Delete notes
* View notes in an organized card layout
* Search notes
* Categorize notes
* Note timestamps
* Local Storage persistence
* Responsive design
* Light/Dark mode
* Violet gradient UI

## 🚀 Getting Started

Both applications are independent React projects.

### ▶️ Running the To-Do App

Navigate to the To-Do application:

```bash
cd todo-app
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in the terminal.

---

### ▶️ Running the Notes App

Open another terminal and navigate to the Notes application:

```bash
cd notes-app
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in the terminal.
