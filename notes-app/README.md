# Notes App

A responsive React notes workspace for Minor Project 04. Capture ideas with titles, content, categories, search, timestamps, and persistent Local Storage.

## Features
- Create, edit, and delete notes
- Search title, content, or category
- Personal, Study, Projects, DSA, React, Important, and Other categories
- Created and updated timestamps
- Local Storage persistence
- Responsive card grid and light/dark mode

## Technologies and Concepts
React, JavaScript, JSX, CSS, functional components, props, `useState`, `useEffect`, conditional rendering, event handling, `map`, and `filter`.

## Run locally
```bash
npm install
npm run dev
```

Notes and theme preference are stored in the browser's Local Storage.
