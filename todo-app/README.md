# To-Do App

A responsive React task manager for Minor Project 04. Add tasks, optional due dates, completion status, editing, deletion, filters, and a persistent light/dark theme.

## Features
- Create, edit, delete, and complete tasks
- Pending, completed, and all filters
- Optional due dates
- Local Storage persistence
- Responsive layout and accessible controls
- Light/dark mode with violet gradient styling

## Technologies and Concepts
React, JavaScript, JSX, CSS, functional components, props, `useState`, `useEffect`, conditional rendering, event handling, and array methods such as `map` and `filter`.

## Run locally
```bash
npm install
npm run dev
```

Tasks and theme preference are stored in the browser's Local Storage.
